# UI 图标尺寸、卡片留白与字幕选择布局

2026-10-15。延续 A 方案的深色渐变、高光边缘和青绿色状态色，调整实际 uGUI 排版。

## 布局变化

- 常规独立图标按钮固定为 **64 × 64 Canvas 单位**，图形居中，工具栏按相同间隔重排；文件、SMB、Emby、弹窗返回、虚拟键盘和快捷字幕浏览器均使用同一工厂入口。快捷播放条已有的 88 × 88 大目标仍保留，播放圆形按钮也使用正方形点击范围。
- 外层页面卡片与内容之间四边留出 24 单位。设置、投影、字幕样式及诊断卡片使用 24 单位内容边距；独立卡片之间使用 24 单位间隔。子卡片不再压住外层卡片顶部。
- 设置页把标题、调节行和画质行放在各自卡片内部；投影页的页面标题、投影选项、观看参数和格式识别分别排版。播放信息标题与外层卡片、诊断标题与各自卡片边缘均留出空间。
- 字幕选择页的四项操作等宽、等高、等间隔，整体居中；标题和字幕列表共用左对齐线，音轨入口位于底部中央。字幕行铺满列表可用宽度，状态文字有独立留白；内容不足一页时隐藏滚动条。
- 音轨弹窗打开时隐藏字幕二级标签，返回时恢复同一个标签导航和动画对象。弹窗标题与返回按钮按同一高度垂直居中。
- 虚拟键盘按最长一行计算键宽，每行独立居中，避免最右侧按键越出背景。完成、退格按钮使用统一正方形尺寸。

顶部无框标签的悬浮颜色、完整点击范围和非线性横条动画保持原有设计；字幕 Auto / Manual / Off、来源历史、播放和投影操作仍走原有路径。

本地设备复核命令（使用本轮忽略目录内的专用驱动）：

```powershell
python Tools/.runtime/ui-spacing/Device-LayoutValidation.py --serial <PICO_SERIAL> --adb <ANDROID_SDK_ADB> --section transitions
```

首轮设备脚本在点击当帧读取到旧页面状态而断言中断，恢复设置后改为在下一轮命令检查页面状态，并从头运行；首轮记录单独保留，不计入通过数据。

设备自动化使用开发版模拟指针与摇杆，通过共享输入路径检查按钮行为；截图和自动化不能替代真实手柄触发感、双眼可读性和佩戴舒适度验收。Emby 此次使用合成原生界面检查布局，没有重复真实服务器账号回归。
