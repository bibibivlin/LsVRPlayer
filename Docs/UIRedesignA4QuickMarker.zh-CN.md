## 已确定的视觉与交互

- 时间预览保留第三轮放大的字号和深色圆角标签，底部采用平直圆角轮廓，标签悬浮在光束上方并留出间隔。
- 定位标记采用细长竖向光束。中心为清晰的薄亮芯，周围仅有少量海盐青柔光，上下两端渐隐；光束经过射线命中位置，并继续向命中点下方短距离衰减。
- 圆点复用手柄指针的命中点视觉，与光束中心重合显示。面板自身的定位图形由光束承担，不另外叠加大型圆头、进度滑块或图钉连接。
- 光束的亮芯用于精确辨认横坐标，柔光控制在小范围内；不遮住影片名、时间或控制按钮，不加入大面积泛光、闪烁或持续粒子动画。
- 光束和时间标签不拦截射线。时间由实际命中横坐标计算，放大标签或增加柔光不改变命中范围、时间映射或拖动所有权。
- 光束只在上半区跳转预览时显示；离开、失焦、追踪中断、面板切换或取消拖动时沿用现有清理规则。
- 常态播放条保持第三轮外观。全面板背景进度、大面积上半区跳转、居中三按钮、下方独立 X 和无标题 / 无海报要求继续有效。
- 预览目标不改变当前进度色块，提交仍采用已有点击 / 有效拖动松开规则；被取消的拖动不提交。

在实际 Unity 原型中，以轻量 UI 颜色和透明度变化表达这一光束，不以新增场景灯光或全屏后处理为前提。边缘目标的时间标签留在面板可读范围，定位光束始终对准真实目标横坐标。
