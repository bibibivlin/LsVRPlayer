## 当前 APK 的待核对事项

当前两处 Gradle 声明均使用 `org.jellyfin.media3:media3-ffmpeg-decoder:1.9.0+1`，其上游 [POM 记录](Licenses/jellyfin-ffmpeg-1.9.0+1.pom) 标注 GPL-3.0。**项目自有源码采用 MIT，不等于包含这些依赖的完整 APK 采用 MIT，或其公开分发条件已经核对完成。**

公开分发 APK 前，需要针对实际产物完成以下工作：

1. 明确最终使用的解码器及其编译选项、全部适用许可证，以及与 Unity / PICO 运行时的组合条件。
2. 根据适用条款准备对应版本源码、改动和构建说明、必要的再链接材料，以及发布包内应携带的许可证和声明。
3. 将这些材料与实际 AAR / SO / APK 核对，记录版本、来源与产物哈希；不能用不同配置的源码代替所分发二进制。
4. 若现有组合无法满足分发条件，再选择合适的解码方案并重新做音频兼容性验证。不能只删除许可证，或把现有 GPL 二进制改称 LGPL / MIT。

[FFmpeg 官方许可说明](https://ffmpeg.org/legal.html) 说明，适用许可会受启用组件与构建选项影响；不能把 FFmpeg 的一般 LGPL 情况直接套用到当前预编译的 GPL 包。此轮文档完善未替换该依赖，也未完成上述二进制分发核对。
