# 字幕设置与界面对齐修正

日期：2026-10-14，接续 [操作图标与顶部居中](UIIconsAndNavigation.zh-CN.md)。

后续页面切换灰白闪烁的原因与运行时修复见 [切页闪烁记录](UITransitionFlickerFix.zh-CN.md)。本页验证与 APK 数据对应对齐修正完成时的版本。

用户截图中的字幕位置页有三处问题：文字靠近卡片边缘，文字与滑杆缺少统一行中心，字幕二级标签组靠左。本轮修正这些布局，并检查其他页面的同类问题。

## 字幕位置与样式

位置页四行设置统一使用 48 高的文字区域，滑杆 42 高，在行内上下各留 3；名称、滑杆和右侧数值共享中心线。1376 宽卡片两侧各留 24，数值区右对齐便于比较，名称区保持左对齐便于扫描。「选择 / 位置 / 样式」标签独立成组，以内容区域及整个窗口的水平中心为锚点。

![修正后的字幕位置页](Images/UIAlignment/17-SubtitlePosition.png)

样式页的描边、阴影开关与数值、滑杆共用中心线；背景透明度文字与滑杆对齐。三种背景模式按钮等宽，两侧边距相同；明亮、深色预览区域等高，预览文字分别居中。

![修正后的字幕样式页](Images/UIAlignment/04-SubtitleStyle.png)

## 共用控件与其他页面

TextMeshPro 的普通 Middle 对齐以字体行度量计算中心，当前字体的实际字形中心略低。共用 UI 文本改用 Geometry / Midline，按可见字形垂直居中；为中文保留额外行高时，文字区域围绕原布局中心对称扩展。按钮、开关、列表、输入框、时间和数值由此使用一致的垂直居中方式。多行介绍和影片标题仍按其阅读布局顶对齐。

| 页面 | 修正 |
| --- | --- |
| 投影 | 三列选项与格式开关等宽，卡片两侧边距一致 |
| 设置 | 三种画质按钮等宽，右侧与左侧卡片内边距一致 |
| 快捷面板 | 标题与重置按钮共享中心线；字幕开关文本垂直居中 |
| Emby | 顶部标题与导航按钮对齐，视图选择按钮的文字和箭头垂直居中；地址表单标签与输入框等高 |
| Emby 提示 | 加载、空列表、错误及无效影片提示宽度依据实际容器计算，避免超出边缘 |
| 设置数值 | 无单位数值移除尾部空格，避免右对齐后可见文字向左偏移 |

播放字幕保留原有字体对齐与高度定位，只有设置页中的样式预览启用上述字形居中。未调整播放字幕的位置计算、字号规则、距离、设置迁移或操作逻辑。
