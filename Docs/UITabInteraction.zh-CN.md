# 无框标签与指示条动画

日期：2026-10-15，接续 [切页闪烁修复](UITransitionFlickerFix.zh-CN.md)。

主导航「文件 / 投影 / 字幕 / 设置 / 信息」及字幕「选择 / 位置 / 样式」移除悬停底框。悬停与按压只让文字使用和选中状态相同的青绿色，离开后恢复；真正的选中页由下方横条区分。主导航 118 × 64、字幕导航 202 × 60 的点击区域、原有间距和整个窗口居中位置保持不变。透明命中图形与装饰横条分离，横条不参与射线命中。双手同时悬停时，离开一只手不会清除另一只手的文字高亮。

![字幕位置已选中，悬停选择时仅文字高亮](Images/UITabs/19-SubtitleTabHover.png)

![字幕页中悬停文件标签](Images/UITabs/20-PrimaryTabHover.png)

每组标签现在共用一条 76 × 4 的圆角指示条。点击切页时使用临界阻尼运动，先加速后减速，没有额外的弹跳、拉伸或呼吸效果；快速改选会保留当前位置和速度，连续追随新目标，避免从旧标签重新起步或瞬间跳位。主要可见位移在约 0.2–0.3 秒内完成，较长跳转柔和收尾。

动画使用不受播放暂停或 Unity 时间缩放影响的时间步长，限制异常长帧的单次步长；第一次显示、隐藏及失去焦点时直接对齐当前页。字幕二级导航保留为独立的持续对象，内容重绘不会销毁指示条或打断移动。页面选择、返回路径、字幕状态与持久化逻辑沿用原路径。
