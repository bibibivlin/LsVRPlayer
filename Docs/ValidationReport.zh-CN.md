## 稳定性检查

`Validation/device-stability.json` 保存高分辨率截图时的解码状态、进程 PSS，以及 18 次反复打开 H.264 / HEVC / 4K 视频、seek 和播放的记录。18 轮全部通过，循环部分约 138 秒；记录中的解码丢帧为 0。预热后 PSS 约 800.6 MiB，最后约 691.9 MiB，本轮未观察到持续增长。单独播放 8K 测试片时 PSS 约 1,106 MiB。这是一轮短压力检查，不代替原计划中的 60 分钟以上长片、发热与耗电验收。

## 已修复的问题

- Android 原生 GPU 输出、Java 播放状态与 Unity 渲染线程分离，避免逐帧 CPU 拷贝。
- Windows Impacket 只读共享错误清除二进制打开标志会破坏视频字节；仅修正本地测试服务器包装层。
- 部分测试 SMB 服务端的 EOF 包不兼容：字幕按已知文件大小读取，处理正数短读、超长文件和提前 EOF。
- 进度条原先仅滑块可命中；增加整条轨道的透明命中区域，并修复填充/滑块尺寸。
- 虚拟键盘选择按键时输入框失去焦点，原有搜索重绘会销毁输入目标；改为明确完成/搜索后刷新，并增加当前输入预览。
- 状态更新不再销毁正在填写的 SMB 表单；增加服务器编辑和删除入口。
- 开发调试命令移入应用内部私有目录，通过 `adb run-as` 写入；仅 Development/Editor 编译，没有导出的命令接收器。

## 尚未完成的完整首版工作

- PICO 外部合成层、高码率长片性能、长时间热稳定，以及实际 NAS/Wi-Fi 的断线恢复回归。
- HDR 色调映射、相机特定鱼眼/VR180 网格、多种 Cubemap/EAC 排列与元数据自动识别。当前鱼眼和立方体仅提供操作说明中声明的投影布局，未列入上面的实测支持矩阵。
- 完整 ASS 特效、PGS/VobSub 图形字幕、MVC/蓝光 ISO、DRM/Dolby Vision 不在本版已支持范围。
- 佩戴时的文字大小、手柄可达性、长片口型同步和舒适度仍需使用者体验反馈；首次权限对话框、SAF 系统目录选择器也需要完整的人机流程验收。

当前开发场景和 APK 已可用于自己的本地影片与 NAS 共享试用。操作、构建和组件许可见 `BuildAndUse.zh-CN.md` 与 `ThirdPartyNotices.md`。
