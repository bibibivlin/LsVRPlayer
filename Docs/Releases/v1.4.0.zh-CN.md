# L's VRPlayer 1.4.0

面向 PICO 4 的 Android ARM64 VR 视频播放器。包名保持 `com.linxyi.LsVRPlayer`，版本代码由 11 递增为 **12**。

## 新增与改进

- **Emby 局域网发现**：添加服务器时自动搜索局域网内的 Emby 服务器，并可选择服务器公开的登录账户；无法发现服务器或账户时仍可手动输入。搜索结果受网络隔离、服务器发现设置及防火墙影响。详见 [Emby 使用说明](https://github.com/bibibivlin/LsVRPlayer/blob/v1.4.0/Docs/Emby.zh-CN.md)。
- **多 CD 影片续播**：Emby 首页保留服务器的官方续播列表；对于被服务器遗漏的多 CD 电影，依据当前账户的本机历史及官方分段信息补充续播卡片。补充卡片仅显示在本机播放器中。
- **平面与 VR 字幕**：分别保存平面与 VR 文本字幕样式；平面 SRT 和 ASS 合成到视频画面，跟随屏幕尺寸及曲面。ASS 保留脚本样式，并可整体缩放和上下移动；非平面投影仍不显示 ASS。
- **网络进度缩略图**：改进网络长片索引读取、请求复用和拖动时的渐进显示；预览画面标注自身时间，跳转目标时间单独显示。详见[网络缩略图验证](https://github.com/bibibivlin/LsVRPlayer/blob/v1.4.0/Docs/SeekThumbnailNetworkFix.zh-CN.md)。

## 安装与校验

下载 `LsVRPlayer-1.4.0.apk` 安装到 PICO 4。版本代码 12 高于 1.3.0 的 11，沿用正式签名时可直接覆盖升级并保留应用数据。调试签名版本需先备份数据；跨签名切换时卸载会删除应用数据。

`SHA256SUMS.txt` 提供 APK、发布清单、对应源码 ZIP、第三方声明和政策／权限 HTML 的校验值。`release-manifest.json` 记录源码提交、版本、签名证书、ARM64 库及完整 EditMode 测试结果。

## 验证范围与已知限制

发布流水线运行发布工具回归、原生 JUnit 和完整 `VRPlayer.Tests` EditMode 套件，构建非 Development ARM64／IL2CPP／GLES3 Player，并验证签名、版本、权限、运行库及对应源码；结果以发布清单及 Actions 记录为准。

此前针对网络缩略图的真实 Emby 局域网测试涵盖三部 4K 长片和独立播放并发检查；SMB 检查使用合成素材及 `adb reverse`。多 CD 首页修复使用真实 Emby 服务与合成分段视频验证；Emby 发现和字幕改动经过编辑器回归及用户真机确认。上述检查不能证明所有服务器、真实 SMB 长片或物理手柄及佩戴体验均已覆盖。

缩略图首次读取可能需要解析容器，部分编码或资源不足时可能不可用。ASS 不导入 MKV 附件或旁置自定义字体；Emby 保持原始播放，不自动转码；视频解码受头显能力限制，暂不支持 HDR 色调映射。纯画面 VR180 自动投影仍未启用。其他头显兼容性尚未确认。
