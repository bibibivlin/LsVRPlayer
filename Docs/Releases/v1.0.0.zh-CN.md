# L's VRPlayer 1.0.0

面向 PICO 4 的 Android ARM64 VR 视频播放器首个正式版本。包名为 `com.linxyi.LsVRPlayer`，版本代码为 **7**。

## 功能

- 播放本地、SMB 共享及 Emby 服务器的原始视频。
- 支持平面／曲面、SBS／OU、180°／360° 投影，逐片保存格式、距离、全景缩放和播放进度。
- 支持中文 SRT、字幕编码／延时／样式调节、历史记录和收藏。
- 提供完整面板、简易播放控制、摇杆快进快退及全局返回。
- 支持 Emby 媒体库视图、同片 CD 切换、续播、附加篇及原画播放。

## 安装与校验

下载 `LsVRPlayer-1.0.0.apk` 安装到 PICO 4。`SHA256SUMS.txt` 提供 APK 与发布清单的文件校验值；`release-manifest.json` 记录源码提交、签名证书 SHA-256、版本、ABI 与测试结果。

此包关闭 Development Build，使用发布密钥签名。已有调试签名版本无法直接跨签名覆盖安装；卸载会删除应用数据，切换前请先备份。

## 验证范围与已知限制

发布流水线要求原生 JUnit、完整 VRPlayer EditMode 测试、APK 签名、包名、版本、ARM64 库和非调试标志检查通过。既有 PICO 实机验证记录见仓库 `Docs/`；它们不替代本次正式签名包的佩戴验收。

本次发布流水线不验证物理手柄、头显舒适度、长片兼容性或真实局域网服务器。Emby 保持原始播放，不自动转码；设备不支持的编码可能无法播放。无标签纯画面 VR180 自动投影仍受独立真实样本验收门控，当前保留候选与人工采用。
