# L's VRPlayer 1.1.0

面向 PICO 4 的 Android ARM64 VR 视频播放器。包名保持 `com.linxyi.LsVRPlayer`，版本代码由 7 递增为 **8**。

## 新增与改进

- **多语言界面**：设置中可选择跟随系统、简体中文、English 或日本語，立即生效并保存。文件名、影片资料及字幕内容保留原文；隐私与权限说明继续提供中英文。
- **ASS / SSA 字幕**：通过 libass 保留样式、位置与动画，支持本地 / SMB 外部字幕、Emby 原格式外部字幕和 Android MKV 内嵌 ASS。字幕在平面视频画面内显示，支持平面 SBS / OU；非平面投影暂停显示，切回平面后恢复。SRT 保留原有悬浮字幕方式。
- **Emby 剧集浏览**：使用官方季 / 集接口并保持服务端顺序，单常规季直接展开各集，特别篇独立显示；多季先显示季入口。季采用竖幅海报并正确回退到剧海报，集与集详情采用自身横幅缩略图。
- **主面板距离**：显示主面板时，按住同一手柄的中指 Grip 并上下推摇杆，在 1.2–6 米间调整；默认 2 米，重启后保留。视频、字幕及简易面板距离保持独立。修复主面板和手柄指针拉远到视频幕布后方时消失的问题。
- **Emby 图片尺寸**：视图菜单新增大 / 中 / 小三档，大档沿用原布局；七种视图均可调节。按账户配置与媒体库保存，各视图 / 尺寸组合独立恢复滚动位置；季 / 集页也可调整图片大小。
- **导航**：页面返回按钮统一位于标题前。
- **隐私与分发材料**：新增首次隐私确认、离线政策 / 权限 / 第三方许可及源码导出，关闭 Android 自动备份；音频解码改用可重建的 LGPL 共享库。项目自有代码与文档采用 MIT，第三方内容保留各自条款。

## 安装与校验

下载 `LsVRPlayer-1.1.0.apk` 安装到 PICO 4。正式签名的 1.0.0 可覆盖升级；调试签名版本需先备份数据，跨签名切换时卸载会删除应用数据。

`SHA256SUMS.txt` 提供 APK、发布清单、对应源码 ZIP、第三方声明和政策 / 权限 HTML 的校验值。`release-manifest.json` 记录实际源码提交、版本、签名证书 SHA-256、ARM64 库及本轮完整 EditMode 测试结果。

这些记录来自各功能的验证构建，不替代本次最终签名 APK 的佩戴验收，也不代表长片、高码率无线播放或所有真实服务器已经全面验证。

ASS 尚不导入 MKV 附件或旁置自定义字体；复杂脚本、真实网络 ASS 和长片性能需单独验证。Emby 保持原始播放，不自动转码；视频解码受头显能力限制，暂不支持 HDR 色调映射。纯画面 VR180 自动投影仍未启用，可手动设置或采用识别建议。其他头显兼容性尚未确认。
