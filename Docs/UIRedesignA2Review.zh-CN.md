## 已接受的快捷条修改

1. 面板没有「快捷播放」等标题，也不放应用品牌标题。
2. 关闭保持原来的下方独立悬浮圆形 X；面板与 X 之间留出明确间隔，不把它放进控制条按钮行。
3. 不显示视频海报、缩略图或装饰素材；保留当前时间、影片文件名和总时长。
4. 整个面板背景本身表示进度：从左至当前时间位置的色块贯穿面板全高。上半区保留宽而连续的跳转命中区域，不改成细进度轨道；按钮命中优先，悬停预览目标时间，点击跳转，拖动松开提交，取消拖动不提交。
5. 上一部／播放暂停／下一部按此顺序组成严格居中的一组；字幕、音量位于左侧，模式、倍速位于右侧。

下方 X 沿用当前实现的「停止视频、保存进度、返回文件页」语义；默认仅显示 X 图标，悬停提示「停止并返回」。全局返回和自动隐藏保留各自原有行为。字幕、模式与倍速弹窗仍可显示各自名称，这与无标题的基础播放条区分。

### 01 快捷条

![01 快捷条：常态与跳转预览](Images/UIConcepts/A2-01-QuickControls.png)

上下为同一播放条的两个状态，实际只显示一条；图外的「常态 / 跳转预览」是评审标注，不进入产品界面。目标时间预览不改变已播放色块；点击或有效拖动结束后才提交跳转。字幕、音量与模式按钮的悬停提示保持可用。

布局约束：中心播放按钮位于整条面板的水平中心，上一部与下一部等距放在两侧，不能因左侧音量展开而整体偏移。音量展开与收起不得挤动三按钮或改变时间到横坐标的映射。上半区贯穿整条宽度，文字不拦截射线，按钮及弹窗命中优先于背景跳转。

### 02 文件浏览

![02 文件浏览](Images/UIConcepts/A2-02-FileBrowser-v2.png)

保留五个主页面和五个来源。路径负责定位，搜索负责过滤，排序与视频 / 字幕模式各有独立位置。返回沿实际访问历史，上级访问物理父目录；路径显示人可读名称，可通过地址入口编辑，不把配置 ID 当作标题。

本地与 SMB 文件列表不依赖海报或帧提取。目录与视频依靠一致的图标、文字和次级信息区分，长名称提供足够显示空间，文件大小右对齐。底部普通播放栏与快捷条是不同组件，完整面板仍可使用细进度轨道。

图底部的加载、空目录、读取失败是替代状态样本，不是同时出现的三条通知。取消与重试继续使用现有异步操作规则。

### 03 Emby 详情

![03 Emby 影片详情](Images/UIConcepts/A2-03-EmbyDetails-v2.png)

主操作明确写出最近播放的 CD 和时间；「仅继续 CD1」及「CD1 从头播放」保持独立，不用模糊的多个“继续”按钮。最近部分取自现有电影级续播机制，不由分段编号或进度大小推断。

同电影的 CD 分段与花絮 / 本地预告分开，沿服务器官方结果顺序显示。直接打开部分、相邻播放、自动继续和花絮各自的格式继承语义不因外观改动而变化。海报与分段图片仅用于 Emby 提供的内容；缺图状态必须可用。

### 04 投影设置

![04 完整投影设置](Images/UIConcepts/A2-04-Projection-v2.png)

画面投影、立体布局、Full / Half、交换左右眼和单眼 2D 分层显示。VR180 与左右 SBS 分别选择；任意图标也不暗示两者等价。

平面显示屏幕距离，其他投影显示全景缩放；图中平面小样是条件替代状态。重置仅影响当前距离类型。宽度、高度、曲率与鱼眼角度在高级区保留，手动锁状态可见；识别、撤销、采用建议沿用 `PlayerApp` 统一入口，不新增未经验证的纯帧 VR180 自动投影。

### 05 字幕

![05 主字幕样式与快捷字幕选择](Images/UIConcepts/A2-05-Subtitles-v2.png)

主面板保留「选择 / 位置 / 样式」结构。样式参数与明暗背景预览分区，字幕使用自己的材质，菜单文字不受字幕样式影响。

右侧是独立的快捷字幕弹窗。自动、手动与关闭状态应明确区分；选中同名 SRT、内嵌轨道、浏览文件与恢复自动选择各有明确入口。正偏移表示延后。快捷字幕浏览保持独立来源和目录会话，不改变主文件来源或播放队列。

### 06 设置与播放信息

![06 设置与播放信息](Images/UIConcepts/A2-06-SettingsAndInfo-v2.png)

设置按播放、播放行为、字幕与音轨、格式识别分组。播放速度、亮度和质量各自表达数值与选中状态；单片循环、目录连播、自动隐藏不混用同一开关。清空记录放在较低优先级的独立位置。

信息页先提供视频格式、当前播放与缓冲状态，再展开解码、网络等高级诊断。图中参数是演示数据，不是新硬件能力声明。画质变更继续按现有初始化 / XR 恢复 / 质量选择时机生效。

### 07 连接与恢复

![07 SMB 发现、连接与 Emby 登录](Images/UIConcepts/A2-07-Connections.png)

网络发现不展示凭据，连接表单有常驻字段标签。SMB 的列出共享与打开指定共享是不同动作；Emby 明确使用服务器已有账户，记住登录遵循既有令牌机制，不保存密码。

连接中可取消，失败提供检查地址或重试入口。表单、视图菜单和弹层按现有全局返回顺序退出，弹层打开时不让背景滚动或接受穿透操作。图中没有实际账户、媒体地址或凭据。

## 下一轮评审方式

可按编号描述需要调整的区域，例如「01 的面板再矮一点」「03 把分段放到简介前」「05 预览区扩大」。配色和组件语言继续统一为 A，先确认信息顺序、布局和操作边界，再进入可编辑 Unity 原型及代码实现。
