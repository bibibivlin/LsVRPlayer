# 主面板精简与停止返回

2026-10-12（Asia/Shanghai）。按界面截图精简完整面板，并为简易面板增加停止返回入口。

## 界面变化

- 移除顶部的选择影片提示和隐藏面板按钮，将 `L's VR Player` 标题放在顶部标签栏右侧并右对齐；顶部标签栏上移，内容区进一步增加 122 像素。完整面板仍可通过 A／X、菜单键、Tab 或全局返回关闭。
- 移除列表底部的项数／滚动提示和常驻来源状态行。本地／SMB 列表高度从 352 增至 652，仍按视口复用列表行；Emby 面板高度从 550 增至 782，海报墙列表视口从 326 增至 626，保留按视口请求图片和缓存限制。
- 底部播放控件合为一行，保留上一部、播放／暂停、下一部、进度、时间、音量、重试和停止，移除 ±10 秒按钮。摇杆和键盘原有快退／快进仍可使用。
- 移除主面板和投影页的正前方／躺卧入口，以及 R 和开发命令的播放器方向调整；观看方向使用 PICO 系统重置。设备脚本同步移除旧方向命令，运行前需要在系统中调整观看方向。
- 移除存储权限／授权目录按钮。共享存储目录、字幕读取或播放失败且读取权限尚未授予时，按 Android 版本请求系统读取权限。授权后重试，拒绝、不再询问或关闭对话框均结束等待；停止、换片或取消浏览会淘汰旧操作。SMB 和已有系统授权目录不申请共享存储权限。
- 地址栏及简易字幕浏览路径显示中文、日文、韩文等 Unicode 字符；保留百分号和路径分隔符等保留字符的转义。未修改的地址继续使用原 URI，修改后的文件／SMB 地址仅编码一次，保持收藏、历史和返回标识稳定。
- 简易控制条底部新增独立圆形 X。点击停止当前视频并保存进度，取消拖动、字幕浏览与待完成的播放请求，直接打开完整面板的文件页，保留来源和列表位置。错误和操作结果使用短暂反馈浮层。
