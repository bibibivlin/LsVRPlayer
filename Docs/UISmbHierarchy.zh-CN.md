# SMB 分类层级与列表操作按钮

日期：2026-10-16。

“已保存的共享”和“局域网发现”使用独立的分组标题与细分隔线，不显示内容行底板、图标或悬停反馈。标题的所有图形均不接收射线，滚动仍由列表视口处理。

已保存共享的编辑按钮改用铅笔图标，收藏移除按钮使用垃圾桶图标，均采用统一的 64 × 64 画布单位尺寸、30 单位图标和悬浮文字提示。列表内容相应延伸至按钮左侧，保留间隔。最近播放中“所在目录”“影片详情”等需要语义区分的操作保留文字。

分类标题、普通内容行、图标操作和文字操作共用原有的有界行池。复用时恢复按钮可见性、宽度、文本与提示；原有按下条目身份校验继续防止释放时误操作另一条记录。未更改 SMB 凭据、连接逻辑或收藏撤销行为。
