# A 方案第五轮：快捷条渐变与悬停反馈

日期：2026-10-13。继续在概念阶段修订快捷条。当前背景分区与跳转反馈以本页为准，光束语言沿用第四轮，其他已接受页面沿用第三轮与第二轮方案。

![渐变背景与跳转区悬停反馈](Images/UIConcepts/A5-01-QuickControls.png)

## 已确定的修改

- 上方跳转区与下方按钮区之间移除硬水平分界，使用宽而平滑的纵向透明度渐变蒙版，形成一整块连续的圆角面板。
- 渐变作用于背景，文字、图标和光束保持清晰；已播放的海盐青底色与未播放的墨蓝底色均采用同样的柔和过渡。
- 表示实际播放位置的纵向进度前沿保持准确，海盐青进度仍铺满面板全高。本轮移除的是上下功能区的视觉硬边，不是实际播放进度的横坐标标识。
- 指针悬停在有效跳转区时显示光束与目标时间；移到不能跳转的区域时立即隐藏这两项反馈，继续显示原有手柄基础指针。
- 按钮命中优先，保留其原有悬停 / 点击反馈；按钮与下方空白不因渐变而变为跳转区域。
- 渐变不改变既有上半区命中范围。是否显示预览由有效射线命中与交互状态决定，不根据背景颜色或透明度估计。
- 光束、蒙版和时间标签不拦截射线。显示 / 隐藏反馈不触发播放跳转，也不改变正在进行的拖动所有权、取消与提交规则。
- 失焦、追踪中断、面板切换等状态继续按已有规则清理指针操作和预览。

## 图中两个状态

上方示例为「非跳转区悬停」：小型手柄命中点落在下方空白处，不出现光束或目标时间。

下方示例为「跳转区悬停」：命中点位于上方跳转区，出现海盐青光束和较大的目标时间。当前实际进度色块不跟随悬停目标移动。

两条面板是同一控件的替代状态，实际只显示一条。图外状态名称仅用于评审，不进入产品。居中上一部 / 播放暂停 / 下一部、独立悬浮 X、无面板标题、无海报和现有字幕 / 音量 / 模式 / 倍速操作继续有效。
