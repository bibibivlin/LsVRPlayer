# 页面切换灰白闪烁修复

日期：2026-10-15，接续 [界面对齐修正](UIAlignmentFixes.zh-CN.md)。

后续无框标签悬停与共享指示条动画见 [标签交互记录](UITabInteraction.zh-CN.md)。本页 APK 和验证数据对应闪烁修复版本。

## 原因与修复

侧栏、透明背景图标和目录行使用白色顶点底色，再通过 uGUI `ColorBlock` 的渲染器颜色得到最终的深色或透明背景。创建控件、重绘页面或复用列表行时，修改 `colors` 会在运行时触发 0.08–0.10 秒的过渡；它可能从渲染器原来的白色或禁用灰色开始，导致短暂的灰白底板。

在修改前新增 PlayMode 回归，三个场景均复现失败：目录行、快捷图标、来源侧栏在首帧的红色乘数分别约为 0.973、0.965、0.970，而透明背景应为 0。EditMode 的 uGUI 属性更新是即时的，所以先前静态预览及 EditMode 检查没有暴露这个运行时问题。

`UiFactory.SetColorsImmediate` 在控件初始化、导航选中状态更新和目录行复用时，同步应用当前交互状态的最终颜色，再恢复原有过渡时长。它通过 uGUI 自身的状态逻辑处理悬停、按压、选中与禁用，停止旧过渡；正常指针进入、离开和按压仍保留淡入效果。

主界面标签、来源侧栏、色板、播放按钮、快捷图标及目录行统一使用此路径。渐变材质、光影着色器、遮罩、布局和原有点击操作没有改动。
