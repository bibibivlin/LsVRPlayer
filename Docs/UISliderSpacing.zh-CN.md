# 拖动条间距与对齐调整

日期：2026-10-15 至 2026-10-16。检查了 Runtime 中全部 Slider 创建入口及其页面实例，保留现有 A 方案材质和交互路径。

## 调整

此前标题与数值占用过宽的固定框，数值又在框内靠右排列，导致滑轨左右出现不等的空白。新的同行数值滑条按标题实际宽度排版，数值靠近滑轨左对齐，滑轨与相邻文字框或按钮使用 16 Canvas 单位的间隔。数值栏保持固定宽度，数值变化时滑轨不会移动。

| 区域 | 检查及处理 |
| --- | --- |
| 字幕位置 | 延后、大小、视觉高度、距离共用紧凑布局，统一滑轨起止列与数值列。 |
| 字幕样式 | 描边粗细、阴影强度、背景透明度按各自标题宽度排版，移除标题之后的大块空白。 |
| 播放设置 | 速度、亮度的减小/增大按钮与滑轨保持相同间距；重置和数值列对齐；画质选项跟随标题列对齐。 |
| 投影设置 | 检查平面宽度、距离、高度、曲率，以及全景缩放、鱼眼角度。上下两行形式保留，标题/数值与滑轨垂直居中关系统一。 |
| 主播放栏 | 时间靠近进度条排列，并按相邻图标的可见边缘平衡空隙；音量条和进度条与按钮中心线对齐。 |
| 快捷倍速 | 改为减速—滑轨—加速的同行布局，两侧按钮尺寸相同、间距相同。 |
| 快捷音量 | 扩展区域左右内边距相同，平衡与音量图标、上一部图标之间的可见空隙。 |
| 快捷远近/缩放 | 数值与重置按钮统一间距，滑轨上下间距按控件组整理。 |

普通细滑条的透明点击高度由 42 增至 48 单位，滑轨和滑块同步垂直居中。快捷粗滑条保留 62 单位点击高度，修正滑块活动范围：最小、最大值处均完整显示，不再被蒙版裁掉一半。拖动归属、取消和播放进度提交继续使用既有 `OwnedSlider` / `SeekGesture` 路径。
