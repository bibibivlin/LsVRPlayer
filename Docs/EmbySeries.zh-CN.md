# Emby 电视节目层级与图片验证

日期：2026-10-18。适用：有季／集结构的电视剧、番剧等电视节目。

## 行为

- 季列表来自官方 [`GET /Shows/{Id}/Seasons`](https://dev.emby.media/reference/RestAPI/TvShowsService/getShowsByIdSeasons.html)，集列表来自 [`GET /Shows/{Id}/Episodes`](https://dev.emby.media/reference/RestAPI/TvShowsService/getShowsByIdEpisodes.html)。按服务端顺序完整聚合分页，不再使用通用目录的标题排序。
- 第 0 季不计入常规季数量。一个常规季直接展开各集，特别篇在独立分区显示；多个常规季先显示各季，再进入季内各集。判定使用完整季列表，搜索不会因为只匹配一季而改变层级。没有季条目时尝试直接取得该剧各集；只有特别季时保留季入口。
- 季固定竖幅 2:3，优先 `ImageTags.Primary`；缺失时使用 `SeriesId` 对应的 `SeriesPrimaryImageTag`，而非拿剧海报的标签请求季的图片。季接口未带剧海报资料时从当前剧补充。
- 集固定横幅 16:9，优先该集的 `Primary`（Emby 的集缩略图），其次该集的 `Thumb`，缺失时显示占位。不会拿剧海报或剧背景图冒充集缩略图；集详情也使用横幅图片。
- 季／集图片等比完整适配画框，隐藏视图菜单，媒体库原有七种视图偏好不变。搜索、返回、滚动复用、图片可见区调度及取消继续使用现有路径。返回特别篇列表后可见已更新的已看状态。
