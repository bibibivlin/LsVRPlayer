# 真实网络长片进度预览修复

日期：2026-11-16，2026-11-17 完成取消异常处理复查，并根据用户的真实 8K 反馈追加交互防抖。原始记录保存在忽略目录 `Docs/Validation/SeekThumbnails/`；本报告不包含服务器地址、账号、媒体标题、路径或令牌。

## 故障与修复

旧实现每次取帧重新打开媒体和解析索引，只有一个 64 KiB 读取块、24 MiB 传输上限与 6 秒期限。对本次真实 MKV 片源，解析过程在不同位置之间反复读取，尚未产生画面就触发 `read_budget`。另外，界面在每次跨越 2 秒区间时取消旧请求并重新等待 160 ms；长片上的射线抖动会反复打断读取。

修复使用 512 KiB 范围块与 16 块 LRU 缓存（8 MiB），复用当前影片的已解析索引和连接，连续请求分别计算传输预算。单次传输上限 128 MiB、从入队起 20 秒原生期限、25 秒 Unity 等待期限；空闲 5 秒即释放索引/网络资源。失败、取消、切片和停止也会释放，不与主播放或格式识别共用连接、取消令牌或缓冲预算。

网络修复阶段，界面让正在执行的取帧完成，移动只更新一个待处理目标；旧目标的有效图片进入有界缓存，当时只显示匹配当前时间的结果。后续交互修复改为带独立时间标注的渐进显示，见下文。离开进度条、隐藏、失焦和切片仍取消请求，取消后的迟到帧不得显示或缓存。原生失败仅提供阶段、固定原因、读取字节/次数和耗时，不输出原始异常、URL 或凭据。

## 2026-11-17 手抖与连续拖动改进

用户反馈真实 8K 已能取得缩略图，但加载期间手抖经常改变目标，图片尚未显示又进入等待。此前“必须匹配最新目标才显示”的限制仍会让首张慢帧无法出现。

本次为完整/快捷面板共用的预览目标加入空间死区和有上限的防抖：死区半径为进度条宽度的 0.5%，最多 4 个 UI 布局单位；小幅越界稳定 180 ms 后接受，连续越界最多等待 350 ms，达到死区半径 4 倍的明显位移立即接受。防抖只影响缩略图请求，不修改光标、目标时间、拖动所有权或松手跳转的位置。停止移动后即使没有新指针事件，预览仍会完成稳定判定。

读取过程中保留已完成的图片，连续拖动时逐步显示中间完成帧，再继续请求最新目标。图内标注所保留图片的请求时间，底部保持准确跳转时间；取帧失败也保留已有画面。新目标缓存一旦显示，旧的异步结果不得覆盖它。切片、停止、失焦、离开进度条和隐藏仍立即清除预览并取消读取，不能跨影片保留图片。

回归范围为 `SeekThumbnailTests`、`QuickControlsTests`、`SeekThumbnailRenderingTests` 和 `LocalizationTests`，共 179 项。首轮 178 项通过，1 项连续拖动用例因 `.7f` 位于两秒量化边界产生浮点截断而失败；将测试终点改为可精确表示的 `.75f` 后，该项单独重跑 1/1 通过，运行时代码未因该测试调整。覆盖长片手抖、短暂越界、慢速累计移动、防抖最大等待、明显移动、连续换图、取帧失败、缓存迟到保护、切片清空和准确松手跳转。原始记录为 `StabilityFix/editmode-initial.json` 与 `StabilityFix/editmode-corrected-case.json`。

编辑器实际渲染生产组件，检查中文、英文、日文的“预览 时间”标注与底部准确目标时间，三种语言均未截断；截图在忽略目录 `Docs/Captures/SeekThumbnails/Stability/`。这属于布局检查，不代替佩戴头显的可读性与手抖体验。本次未修改原生运行库，也未重复访问服务器或重新运行原生设备测试。

## 复现

使用 `Docs/SeekThumbnails.zh-CN.md` 中的 Gradle 命令构建原生测试包，再执行：

```powershell
python Tools/Device-ThumbnailNetworkTest.py --serial <PICO_SERIAL> --server <EMBY_SERVER_URL> --username <TEST_USERNAME> --count 3
python Tools/Device-ThumbnailNetworkTest.py --serial <PICO_SERIAL> --server <EMBY_SERVER_URL> --username <TEST_USERNAME> --count 3 --concurrent-playback
python Tools/Device-ThumbnailTest.py --serial <PICO_SERIAL> --smb
```

密码使用隐藏输入或临时 `EMBY_TEST_PASSWORD`。脚本只在用户指定账户可访问的前 2000 项中选择时长至少 90 秒、宽度至少 3840 的高码率原始视频，最多 6 个样本；`--min-width 7000` 可单独检查 8K。不存在合格样本时必须报告未验证，不会用 4K 或合成素材充当真实 8K。已有隔离测试包时拒绝覆盖。

首次请求仍需解析真实容器，不能保证立即出现画面；损坏/缺少索引、不支持的编码、平台解码资源不足与超时仍可能返回不可用。指定测试账户没有 8K 片源；用户随后反馈其真实 8K 已能获取缩略图，这不是本轮自动化测量，也不含成功率或时延数据。防抖版本的物理手柄体验、真实 SMB 长片和完整 Unity XR 界面仍待设备验收，不能从上述真实 Emby 4K 的成功率推断。
