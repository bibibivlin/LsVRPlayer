# 开关动效与设置排版调整

日期：2026-10-15。基于既有 A 方案的原生 Unity uGUI 实现。

## 行为与视觉

二态设置使用共享的 `UiSwitch`：设置立即应用，滑块位移采用临界阻尼缓动，颜色随运动平滑过渡。快速反向切换保留当前位移和速度，使用非缩放时间，因此暂停播放和 `timeScale=0` 时仍可完成动效。初次显示、隐藏、应用失焦时直接呈现已应用的状态，避免出现过时的动画。

轨道统一为 84 × 44 Canvas 单位，滑块为 36 × 36；沿用界面青绿色、浅色滑块及现有材质的渐变高光。整行保留透明点击区域，悬浮反馈只作用于文字和开关，不出现整行按钮底板。

覆盖播放行为、自动加载字幕、字幕描边/阴影、字幕跟随、快捷字幕总开关、投影辅助选项、目录 VR180 偏好、SMB 保存密码/加密及 Emby 记住登录。播放、静音等传输操作及互斥选项组保留各自的控件语义。

开关原位更新，不再通过重建整个页面切换状态。快捷字幕的文件/轨道列表独立刷新，避免关闭字幕或异步加载完成时打断开关动效；保留 Auto / Manual / Off 和关闭前的选择。字幕预设的高亮随自定义样式同步更新。

## 排版

- 播放行为：移除逐行深色按钮底板，左侧文字与右侧开关分别对齐，行间距扩大。字幕自动加载使用相同的轻量布局。
- 字幕样式：描边开关、描边颜色和粗细分层排列；阴影开关与强度分行。背景类型、颜色、透明度移至预览列下方，保持两列一致的内边距。

Unity 6000.3.23f1：编译与 Console 无错误；552 / 552 EditMode、9 / 9 PlayMode 通过。增加了状态立即应用、暂停下运动和颜色过渡、快速反向切换、外部状态同步、隐藏后恢复、透明点击区域、禁用交互及页面不重建的回归。区分“阴影”预设与开关的自动化名称后，32 / 32 界面用例再次通过。

PICO A8110 开发版 APK：5 / 5 交互检查通过，覆盖四个设置开关的持久化、描边与阴影、投影手动锁定、字幕跟随和快捷字幕连续关闭/恢复。8 张设备截图及录屏已检查；实际录屏逐帧可见滑块的中间位置与轨道颜色过渡。连续 177 次采样保持有效佩戴、应用焦点和新鲜诊断。

首次设备运行误点了同名“阴影”预设，保留失败记录并恢复设备后，使用明确的开关目标重新完成整段回归；未拼接两次结果。最终播放器设置、既有开发命令文件与 USB 唤醒设置均逐字节或按原始缺失状态恢复并验证。未修改 PICO 熄屏超时。字体及项目设置保留本轮开始时的文件内容。

原始记录位于忽略目录 `Docs/Validation/UISwitchMotion/`，复现脚本位于 `Tools/.runtime/ui-switch-motion/`。设备输入通过开发版模拟指针进入共享 `VrUiInput` 路径，不能替代物理手柄手感、双眼可读性和舒适度的主观验收。使用短 Recognition 片段，不代表长片兼容性验证；本轮未进行真实 SMB/Emby 登录测试。
