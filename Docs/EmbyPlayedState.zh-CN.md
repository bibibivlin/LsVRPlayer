# Emby 播放状态与详情操作布局

2026-10-17。

## 行为

- “继续播放”卡片提供独立勾号操作，点击后直接标记为已播放，不进入详情或启动视频。按钮从 64×64 缩为 44×44，图标为 22×22；默认隐藏，悬浮到整张卡片时显示，移到子按钮时保持显示，所有指针离开或关闭面板后隐藏。隐藏时不接收点击。悬浮提示仅显示“标记为已播放”，移除了括号内的 CD 范围说明。
- 影片详情新增“标记为已播放 / 标记为未播放”。续播、从头播放及状态按钮使用相同宽高、字号与图标位置，CD 和时间独立显示；分段电影保留影片级续播与“仅继续 CD1”的区别。
- 电影操作先读取服务器最新资料及官方 `AdditionalParts`，覆盖主片与全部正片 CD。`Type=Video, ExtraType=AdditionalPart` 仍属于正片；花絮、预告、其他电影和剧集不进入这个范围。单集、花絮自身仍可独立标记。
- 每项使用 Emby 官方已播放接口的 `POST /Users/{UserId}/PlayedItems/{Id}`；取消标记使用 `DELETE`，校验服务器返回的状态和零续播位置。认证继续使用请求头，拒绝认证重定向，未添加 URL 令牌。[Emby 官方说明](https://dev.emby.media/doc/restapi/Playback-Check-ins.html)。
- CD 请求按服务器顺序发送，主片最后提交。多项操作无法作为服务器事务提交；部分失败时保留已成功结果，显示错误并允许重试。取消后不继续提交其他 CD，也不让旧回调替换新账户 / 页面的状态。
- 更新当前及返回栈中的列表、影片和分段资料，清除对应本地续播位置，保留字幕、格式、手动锁、距离、缩放及历史身份。正在播放时先排空已有上报并提交旧会话停止，再标记；旧会话之后的快照、进度保存和自动接段不会撤回此次标记。主动重开或显式切换 CD 后恢复正常进度记录。
