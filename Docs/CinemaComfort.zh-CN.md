# 平面观影舒适调节

设置 → **观影舒适** 提供独立的影片高亮压缩和字幕亮度；设置 → **观影背景** 新增 **哑光幕墙**。原四种背景和枚举值保持不变。

这是针对第一版背景试用反馈的第二轮实现。设计依据及证据边界见 [研究报告](CinemaBackgroundResearch.zh-CN.md)。软件功能与渲染检查不能代替戴机光晕、画质与舒适度验收。

## 使用与对照

- **高亮柔和压缩**：关闭、轻度、中度、较强。主要压低亮部，较暗区域保留；会改变高光表现。默认关闭。
- **字幕亮度**：30%–100%，默认 100%。降低字幕颜色亮度，保留透明度、字体颜色比例及描边；支持普通外部/内嵌文字字幕和 ASS。烧录字幕属于视频像素，随影片处理。
- **哑光幕墙**：固定中性墙面、地面和顶面层次，无屏幕周围亮圈、周期条纹、倒影或内容驱动变化。背景亮度单独调节，柔光范围不适用于该模式。
- **收起面板预览**：隐藏设置面板后观察，避免菜单亮度影响判断。

四个一键对照均使用纯黑背景：

| 对照 | 高亮压缩 | 字幕亮度 |
| --- | --- | --- |
| 原片 | 关闭 | 100% |
| 仅字幕 | 关闭 | 70% |
| 仅高光 | 中度 | 100% |
| 组合 | 中度 | 70% |

先用同一片段比较原片和组合，再分别比较仅字幕与仅高光。确定亮度处理后，手动选择哑光幕墙，判断背景是否带来额外收益。选择“原片”恢复纯黑和未启用舒适处理的状态，但不重置原有每影片亮度、字幕样式、格式锁、距离或播放位置。

这些设置全局保存、跨影片生效；只在平面投影启用。切到全景时暂不应用，返回平面恢复所选值。当前播放器针对 SDR，本功能不增加 HDR 解码/色调映射能力。

## 渲染实现

`CinemaComfortSettings` 作为现有 v3 设置中的可选对象。旧设置、缺失对象或 null 保持关闭压缩、字幕 100%；非法值归一化。保留 v1 → v2 → v3 迁移以及每影片状态。

影片在线性 RGB 中先使用现有影片亮度增益，再按最大颜色通道应用统一缩放，避免逐通道裁切改变 RGB 比例。固定曲线不读帧历史、不自动调曝光、不 seek，也不增加视频回读或解码工作。

曲线参数以线性参考白为 1：拐点 k=0.35，轻/中/强在输入 1 时输出 p=0.85/0.75/0.65。对 k < x ≤ 1：

```text
a = (1 - p) / ((p - k) * (1 - k))
f(x) = k + (x - k) / (1 + a * (x - k))
```

对 x > 1，使用 `s = ((p-k)/(1-k))²` 延续：

```text
f(x) = 1 - (1-p) / (1 + (x-1) * s / (1-p))
```

曲线在拐点和输入 1 处的一阶导数连续，对高于 1 的影片增益输入平滑趋近 1；不在曲线前裁切高亮。关闭时直接走原有像素路径。参数只是本轮可比较的工程候选，不代表设备物理亮度百分比或已验证的最优值。

字幕增益与影片曲线独立。ASS 在解预乘和颜色转换后应用增益，再按原 alpha 合成。SDF 字幕处理预乘颜色而保持 alpha；字幕底框的颜色也随增益降低。材质属于字幕实例和字库图集，不修改菜单共享字体材质；相同字幕文本下调亮度也会立即刷新。字幕样式预览使用相同增益。

UI 改动通过 PlayerApp；离散选择立即保存，字幕滑块释放/离页时保存，不在拖动每帧写盘。诊断新增 `cinemaHighlights`、`cinemaSubtitleBrightness`、`cinemaComfortActive`；最后一项表示当前为可应用的平面投影，不代表开关必然开启。
