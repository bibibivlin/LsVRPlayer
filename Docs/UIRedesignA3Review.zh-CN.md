## 01 快捷条

![01 放大跳转预览](Images/UIConcepts/A3-01-QuickControls.png)

相对第二轮，预览点直径约放大至 1.7 倍，目标时间标签与字号约放大至 1.6–1.8 倍，竖线加粗。这是概念尺度起点，实际视角和阅读尺寸仍需在头显原型中校准。

预览时间标签不应小于常态时间文字，不遮挡影片名，也不拦截射线。预览点仅表现射线所在目标位置，不成为传统进度滑块；已播放色块仍贯穿面板全高，预览期间维持原播放进度，跳转提交规则不变。

其余已确定要求保留：无基础面板标题、无海报，上一部 / 播放暂停 / 下一部居中，上半区连续跳转命中，下方 X 独立悬浮。图外常态 / 跳转预览标签不进入产品。

## 03 Emby 影片详情

![03 展开的演员与主创](Images/UIConcepts/A3-03-EmbyDetails.png)

删除简介附近折叠的「演员与主创」菜单入口。演员与主创在影片分段之后、花絮与预告之前直接显示为一行头像卡片，包含名称与角色；横向滚动覆盖服务器返回的完整名单，不以首屏可见卡片数或原有 24 人截断作为名单总数。

首屏显示若干头像与下一张卡片的局部边缘，左右滚动箭头和裁切提示表达后续内容。卡片池与图片请求保持有界，按视口加载，保留服务器顺序；点击单个人物继续进入既有的人物页。头像缺失时使用统一占位而不丢失该人物。

影片详情可纵向滚动，演员条单独横向滚动。海报与人物图片保持来源图片的比例，通过视口滚动容纳较长内容，不靠压缩或拉伸图片腾出空间。未来实现需沿用输入轴仲裁：悬停 / 操作演员条时，水平输入滚动演员条，不同时触发播放跳转；离开、返回或追踪中断时按原规则取消并要求回中。

影片级 / 当前分段续播、CD 和花絮隔离、普通完整面板底栏等保留第二轮设计。概念中的人物头像为生成的虚构演示人物，不是用户媒体或真实演员名单。

## 05 字幕

![05 精简后的字幕界面](Images/UIConcepts/A3-05-Subtitles.png)

快捷字幕删除「自动选择」「手动选择字幕文件」两个模式单选项及其中重复的文件名。已有外置 SRT / 内嵌轨道候选行承担选择功能，直接用行选中标记表达当前字幕；不以新控件替换被删除的重复组。

字幕开关、偏移与归零、候选列表、选择字幕文件、恢复自动选择继续沿用既有功能。底层每影片 Auto / Manual / Off 的保存与恢复语义仍完整保留，视觉精简不改变这些状态，也不增加模式切换功能。

样式页移除预览下方「位置：大小 / 高度 / 距离」提示卡、解释文字、信息图标与箭头。原有「选择 / 位置 / 样式」分页保留；回收的空间用于现有预览或留白，不添加替代教程卡。

## 06 设置与信息

![06 同页展示诊断数据](Images/UIConcepts/A3-06-SettingsAndInfo.png)

左侧设置页保持第二轮样式与信息顺序。右侧信息页删除「高级诊断」折叠 / 跳转入口，直接列出当前已有的诊断数据，按解码与渲染、缓冲、网络、应用分组。

需要保留的数据包括：解码器、视频尺寸 / 编码 / 帧率 / 码率，播放与缓冲位置、剩余缓冲、正在加载、缓冲内存、意外缓冲次数 / 时长；当前有效 SMB 会话的实际网络速率、请求数、平均请求大小、平均读取耗时、P95 与错误；解码丢帧、GPU 更新帧、投影 / 立体、后端状态 / 错误、质量、应用版本与图形 API。网络字段只显示当前有效会话数据，不从过期快照补值。

字段在同一页面按需纵向滚动，不新增二级诊断页或折叠控件，不新增诊断采集、图表、复制 / 导出或媒体路径展示。字号、分组间隔与字段排列优先保障可读性；图中样例参数不代表实测结果。
