# 操作图标与顶部居中

日期：2026-10-14，接续 [视觉细化记录](UIVisualRefinement.zh-CN.md)。

后续的字幕设置及共用控件对齐修正见 [界面对齐记录](UIAlignmentFixes.zh-CN.md)。本页 APK 和验证数据对应图标改造完成时的版本。

顶部「文件 / 投影 / 字幕 / 设置 / 信息」独立成组，以完整窗口的水平中心为锚点。右侧应用名称和文件来源侧栏不参与其居中计算；现有窗口的标签组宽 622，范围为 409–1031，中点为 720，与 1440 宽窗口的中点一致。

## 图标替换

| 范围 | 操作 |
| --- | --- |
| 文件浏览 | 打开输入地址、搜索；已有返回、上级、刷新、收藏补充悬停说明 |
| SMB 工具栏 | 添加服务器、重新扫描、停止扫描 |
| 播放底栏 | 重试播放、停止播放；播放 / 暂停和音量保留原图标，并补充对应说明 |
| Emby | 返回、首页、刷新、搜索、清空搜索、演员列表左右浏览 |
| 主面板二级页与键盘 | 返回、取消编辑、完成输入、退格 |
| 快捷字幕文件浏览 | 返回字幕、上级、刷新 |

图标由现有 `QuickIconGraphic` 的线段和圆弧直接绘制，使用同一套笔画、颜色及按钮材质；未引入图片图标、图标字体或额外依赖。按钮保留原操作、命名和点击范围。

排序、文件类型、字幕编码、投影布局、识别模式、重置 / 撤销识别、账户与服务器、删除 / 移除及带有 CD / 进度的续播说明继续使用文字。「取消读取」也保留文字，避免其被误认成关闭窗口。

每个画布共用一个悬停提示层，射线停留约 0.32 秒后显示名称；提示跟随动态播放 / 暂停状态。提示位于滚动遮罩外，全部装饰不参与射线命中；离开目标、关闭页面、失去焦点或暂停后清除。两只手的提示按最近进入的有效目标显示。
